edit the Chart.yaml file and add the following

dependencies:
  - name: mysql
    version: "9.4.5"
    repository: "https://charts.bitnami.com/bitnami"
    condition: mysql.enabled
    import-values:
      - child: image
        parent: mysql_image
  - name: rabbitmq
    version: "11.2.2"
    repository: "https://charts.bitnami.com/bitnami"
    condition: rabbitmq.enabled

in the deployment.yaml file add following line after kind: Deployment
{{ .Values.mysql_image }}
git push
git pull
helm template my-first-chart/
